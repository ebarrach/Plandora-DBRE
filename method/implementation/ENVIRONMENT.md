# Environment

Record the actual versions and installation commands used for:
- Windows
- IntelliJ IDEA and enabled plugins
- Air and the selected agent
- JDK used to run tools
- JDK and language level used for Plandora
- Eclipse and SQLInspect
- Database server and JDBC driver
- Apache Ant
- Python, if analysis scripts require it
- Git, GitHub CLI and Subversion
