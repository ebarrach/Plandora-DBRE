# Contribution workflow

1. Create a feature branch from develop.
2. Make focused changes and verify them.
3. Open a pull request targeting develop.
4. Describe changes, validation and remaining limitations.
5. Integrate reviewed results through a develop-to-main pull request.

Do not edit the original Plandora reference sources.
Keep reproducible scripts and evidence alongside results.
Never commit passwords, tokens, local database volumes or IDE caches.
