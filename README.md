# Plandora DBRE — INFOM218

Database reverse engineering and assessment of Plandora.

Reference version: SVN revision 348.
Validated scope: 24 tables covering projects, requests, tasks,
resource allocation, capacity planning and history.

## Contribution workflow

1. Create a feature branch from develop.
2. Open a pull request targeting develop.
3. Submit develop to main through a pull request.
4. Obtain approval from another collaborator before merging into main.

Preserve the original reference sources and record evidence with file paths
and line numbers. Keep SQLInspect results separate from complementary analysis.
